# Shyamal Personal OS Skills (`shyamal-assistant` + `shyamal-sweep`)

A token-smart, two-skill personal operating system for daily communications, strategic decision-making, and multi-source intelligence sweeps.

## Included Skills

1. **`shyamal-assistant/`** — Daily-driver assistant for drafting/reviewing emails, WhatsApp/LinkedIn messages, personal/financial/career decisions, and celebration wishes.
   - Enriched with **Two-Pass AI-Tell Cleanup** (`avoid-ai-writing`), **7-Rung YAGNI Ladder & 3-Tier Review** (`ponytail`), **Graph-First Token Cache** (`graphify`), **Stuck-State Router & 8 Lateral Techniques** (`lateral-thinking`), and **15 Creative Techniques** (`claude-creativity`).
   - Enforces the **Ironclad Outbound Lock** (drafts only; never sends directly).

2. **`shyamal-sweep/`** — Deep multi-source intelligence and planning skill across Gmail, Google Drive/Docs/Sheets, Google Calendar, Notion, Web Search, and local workspace files (`Finances`, `Holidays`, `Interviews`, `Topics`).
   - Uses **Watermark Delta-Sweeps (`after:<last_swept - 2d>`)** and **Markdown-State / HTML-View separation** to cut token consumption by 60–80%.
   - Maintains a persistent **Personal Knowledge Graph** (`GRAPH_REPORT.md`, `graph.json`, `graph.html`) with `[EXTRACTED]`, `[INFERRED]`, and `[AMBIGUOUS]` epistemic provenance tags.
